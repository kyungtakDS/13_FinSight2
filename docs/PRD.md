# PRD: FinSight2

## 목표
카드사에서 내려받은 CSV 명세서를 올리면, 30초 안에 "이번 달 어디에 얼마를 썼고 안 쓰는 구독이 무엇인지"를 알려준다.

## 사용자

| | 페르소나 | 빈도 | 성공 조건 |
|---|---|---|---|
| P1 | 월말의 직장인 (핵심) | 월 1회 | "식비가 18만원 늘었네"를 30초에 |
| P2 | 경비 정리하는 프리랜서 | 분기 1회, 파일 3–4개 | 카테고리 합계를 세무자료로 |
| P3 | 구독 다이어터 | 1회 | 해지할 구독 2건을 특정 |
| P4 | 링크 타고 온 비회원 | 1회, 20–40초 | `/demo`에서 결과를 보고 "내 것도" |

## 핵심 기능 (유즈케이스)

1. **UC-01** 가치 제안·데이터·결제 고지를 읽는다 — 무엇이 전송·저장되는지와 반복청구·해지·환불 조건을 안다
2. **UC-02** 샘플 리포트(`/demo`)를 로그인 없이 본다
3. **UC-03/04** Google 계정으로 가입·로그인 / 로그아웃
4. **UC-05** 잔여 분석 횟수 확인 — Free "이번 달 n/3", Pro "n/20"
5. **UC-06** CSV 명세서 업로드 — 원본 저장 + 분석 레코드 생성
6. **UC-07** 분석 진행 상황 확인 (60–180초)
7. **UC-08** 결과 열람 — 카테고리 구성비 · 월별 추이 · 정기구독 후보 · 텍스트 인사이트 4개 영역
8. **UC-09** 과거 분석 목록에서 하나 열기 — 기간·총액으로 식별
9. **UC-11** 분석 1건 삭제 — DB 행 + Storage 원본이 **함께** 사라진다
10. **UC-12** 실패한 분석 재시도 — 최대 2회, 횟수 미차감
11. **UC-13** 한도 소진 안내 — Free/Pro 차이, 초기화 시점, 가격
12. **UC-14/15** Pro 구독 시작 / 결제·구독 관리 (Polar Checkout · Customer Portal)
13. **UC-18** 구독 상태 동기화 — 서명 검증 웹훅이 갱신·실패·취소를 멱등 반영

## 제약

- **파일**: CSV only (XLSX·PDF는 명확한 거부 + 변환 안내), 2MB / 3,000행 이하
- **한도**: Free 월 3회 / Pro 월 20회. 달력 월 KST 기준. **실패는 차감하지 않는다**
- **가격**: Pro 월 ₩9,900 (가설. Polar 상품 설정이 청구 source of truth)
- **프라이버시**: 원본 CSV는 비공개 버킷에 보관하고 자동 삭제하지 않는다. DB에는 요약만. PII 마스킹 후 Claude에 전송하되 **가맹점명과 금액은 분류에 필요하므로 그대로 전송된다** — 이 사실을 고지에 숨기지 않는다

## MVP 제외 사항

- 다중 파일 병합 (P2에게 가장 아쉬움 — 다음 1순위)
- 카테고리 오분류 수정 UI
- 원본 재다운로드 · 계정 자동 삭제 (요청 시 수동 처리)
- 예산 설정·알림 · 결과 내보내기 · 오픈뱅킹 연동 · 팀 계정 · 모바일 앱

## 디자인

- 데이터를 읽는 화면이다. 차트와 숫자가 주인공이고 크롬은 조용해야 한다
- 금액은 `font-variant-numeric: tabular-nums`로 자릿수를 맞춘다
- 라이트/다크 양쪽을 지원한다
- **빈 상태를 먼저 설계한다** — 분석 0건인 대시보드가 다음 행동(업로드 안내 · 샘플 CSV · `/demo`)을 알려주지 못하면 실패다. 데이터가 없을 때 빈 차트를 그리지 마라
- 거래 3건뿐이면 도넛·추이 대신 표로 대체한다
- 모바일에서 차트는 컨테이너 폭 기준, 표는 가로 스크롤 컨테이너 안에 둔다
