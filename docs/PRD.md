# PRD: FinSight

## 목표
프리랜서·1인 사업자가 카드 명세서 CSV를 올리면 사업 경비 후보를 자동 분류해, 세무사에게 그대로 넘길 수 있는 정리본을 만들어 준다.

## 사용자
프리랜서·1인 사업자. 종합소득세 신고를 앞두고 카드 명세서에서 경비 처리 가능한 지출을 골라내야 하지만, 수백 건을 직접 분류할 시간도 세무 지식도 없는 사람.

일반 소비자용 가계부(뱅크샐러드·토스)는 마이데이터로 지출을 보여주지만 "이 지출이 경비인가"에는 답하지 않는다. 그 공백이 이 제품의 자리다. 사용자는 카드사 사이트에서 CSV를 직접 내려받아 올리는 수고를 감수하는데, 그 대가가 절세액이기 때문에 감수한다.

## 핵심 기능
1. **카드사 CSV 업로드** — 인코딩(cp949/utf-8)과 컬럼 구조를 자동 판별해 정규화한다. 카드사마다 다른 양식을 사용자가 맞춰줄 필요가 없다.
2. **경비 분류** — 거래별로 `사업 경비 / 개인 지출 / 애매`를 판정하고 판정 근거를 한 줄로 붙인다.
3. **절세 리포트** — 경비 처리 가능 추정액, 계정과목별 집계, 세무사 전달용 파일 다운로드.

## MVP 제외 사항
- 마이데이터·오픈뱅킹 자동 연동 (CSV 수동 업로드만 지원)
- 팀·법인카드 다인 계정 및 권한 관리
- 세금 신고서 자동 작성·제출
- Google 외 소셜 로그인 (카카오 포함)
- 다단계 요금제 (Polar 단일 상품)

## 과금 경계
- **무료**: 절세 추정액 + 상위 3개 인사이트까지 화면으로 확인
- **유료**: 전체 거래 분류 내역, 시계열 대시보드, 세무사 전달용 파일 다운로드

사용자가 "내 돈 얼마"라는 자기 숫자를 본 뒤에 결제하게 하는 구조다. 다운로드를 막았기 때문에 무료로 일을 끝낼 수는 없다.

## 법적 포지셔닝
세무 자문이 아니라 **경비 후보 정리 도구**다. 리포트 문구는 "경비 처리 가능성이 높은 항목", "예상 절감액(참고용)"으로 쓰고, 화면·PDF·약관에 "본 서비스는 세무 자문이 아니며 최종 판단은 세무대리인과 상의하십시오"를 명시한다. 단정적 지시("경비 처리하세요", "환급받으세요")는 쓰지 않는다.

## 디자인
- 신뢰형 미니멀. 사용자에게 카드 명세서를 요구하는 제품이므로 화면의 신뢰도가 곧 전환율이다. 금융·세무 서비스의 시각적 관습을 따르고 장식을 최소화한다.
- 무채색 기반 + 포인트 컬러 1가지(딥블루 계열). 데이터 밀도가 높은 대시보드.
